# Проектная работа спринта 5

Необходимо разработать и интегрировать интеллектуального ассистента в веб-приложение. Проект выходит за рамки простого создания чат-бота и включает полную цепочку разработки и развёртывания решения в продакшн-среду.
В основе проекта будет готовое веб-приложение из репозитория. Это приложение уже готово к работе с внешними сервисами, но нужно расширить его возможности, интегрировав в него интеллектуального ассистента.
В качестве платформы для создания и настройки ассистента требуется использовать Rasa (платформа для построения диалоговых систем, чат-ботов и AI-ассистентов). За счёт подключения LLM модели получится сделать ассистента умным.
После того как ассистент будет настроен и запущен, его необходимо интегрировать с React-приложением через API. Основное внимание будет уделено работе ассистента с текстовыми запросами, распознаванию намерений и предоставлению персонализированных ответов на основе обученной модели. Завершающим этапом работы станет внесение изменений в виртуальную машину с помощью Terraform.
